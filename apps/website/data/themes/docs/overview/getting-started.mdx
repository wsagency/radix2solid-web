# Getting started

<Description>Install Radix Themes and start building in minutes.</Description>

Radix Themes is a pre-styled component library that is designed to work out of the box with minimal configuration. If you are looking for the unstyled components, go to [Radix Primitives](/primitives).

## Installation

Getting up and running is quick and easy.

### 1. Install Radix Themes

Primitives and Themes are published on npm as 0.1.0-rc.4 (release candidate, dist-tag `next`): [Primitives](https://www.npmjs.com/package/@wsagency/radix2solid-primitives/v/0.1.0-rc.4) and [Themes](https://www.npmjs.com/package/@wsagency/radix2solid-themes/v/0.1.0-rc.4). These are release candidates, not stable releases. The `latest` tag still points to rc.1 for both packages; use the exact-version install commands below. Themes depends on Primitives, so map its transitive dependency to the same npm version. The packages require `solid-js` and `@solidjs/web` `2.0.0-rc.15` with matching signals/compiler/babel packages, compiled by `@solidjs/vite-plugin` `3.0.0-next.50`. With pnpm, add to `pnpm-workspace.yaml`:

```yaml
overrides:
  solid-js: 2.0.0-rc.15
  '@solidjs/web': 2.0.0-rc.15
  '@solidjs/signals': 2.0.0-rc.15
  '@solidjs/compiler': 2.0.0-rc.15
  '@solidjs/babel-plugin': 2.0.0-rc.15
  '@wsagency/radix2solid-primitives': 0.1.0-rc.4
```

Every “Download runnable sandbox” archive under the documentation demos ships the pinned Solid workspace, including exact `minimumReleaseAgeExclude` entries for these Solid versions and all five published package versions. With npm, set the equivalent Solid `overrides` in `package.json` and use `"@wsagency/radix2solid-primitives": "$@wsagency/radix2solid-primitives"` to reuse the exact direct dependency; with Yarn use `resolutions`, and with Bun use `overrides`, mapping Primitives to `0.1.0-rc.4`. Keep the exact Solid versions in every package manager's resolution rules.

#### Complete application

The [runnable Combobox sandbox](/sandboxes/combobox-css-modules.tar.gz) uses exact npm package versions and includes RC15 tooling, CSS, and license files. Extract it, run `pnpm install`, then `pnpm dev`. [Combobox](/themes/docs/recipes/combobox), [Command](/themes/docs/recipes/command), [Tree](/themes/docs/recipes/tree), and [Splitter](/themes/docs/recipes/splitter) are recipes using native Primitives; they are not new Themes package exports.

Requirements: Node.js `>=22.12.0` for your build (this project's own tooling uses Node 24.21). The packages are built with TypeScript 7.0.2 and their published types are also checked with TypeScript 5.9.3. `postcss` is an optional peer dependency, needed only if you use the [PostCSS plugins](/themes/docs/theme/breakpoints#postcss-plugins); importing the compiled CSS needs no PostCSS setup.

Icons are a separate package and Themes does not need it. With [Radix Icons](/icons) installed, the first icon adds about 1.3 kB (0.6 kB gzip) to an app that already renders a Themes `Button`; see the [icons page](/icons#installation) for the measurement. Custom icons are your own SVG or Solid component.

### 2. Import the CSS file

Import the global CSS file at the root of your application.

```ts
import "@wsagency/radix2solid-themes/styles.css";
```

### 3. Add the Theme component

Add `Theme` around your application. For a client-rendered app, mount into the root element in your HTML document:

```tsx
import { render } from "@solidjs/web";
import { Theme } from "@wsagency/radix2solid-themes";
import MyApp from "./your-app";

const root = document.getElementById("root");
if (!root) throw new Error('Add <div id="root"></div> to your HTML document.');
render(() => <Theme><MyApp /></Theme>, root);
```

### 4. Start building

You are now ready to use Radix Themes components.

```jsx
// your-app.tsx
import { Flex, Text, Button } from "@wsagency/radix2solid-themes";
export default function MyApp() {
  return <Flex direction="column" gap="2">
			<Text>Hello from Radix Themes :)</Text>
			<Button>Let's go</Button>
		</Flex>;
}
```

## Customizing your theme

Configuration is managed and applied via the [Theme](/themes/docs/components/theme) component.

### Basic configuration

Pass [configuration](/themes/docs/components/theme) to the `Theme` to customize appearance.

```jsx line=2
import MyApp from "./your-app";
<Theme accentColor="crimson" grayColor="sand" radius="large" scaling="95%">
	<MyApp />
</Theme>;
```

### Using the theme panel

`ThemePanel` is a drop-in component that allows you to preview the theme in real time. Visit the [component playground](/themes/playground) to see it in action.

To add `ThemePanel` to your app, import it from the package and drop it inside your root `Theme`.

```jsx line=6
import { Theme, ThemePanel } from "@wsagency/radix2solid-themes";
import MyApp from "./your-app";
export default function () {
  return <Theme>
			<MyApp />
			<ThemePanel />
		</Theme>;
}
```

The panel offers every built-in accent and gray color but loads none of them. It works with `styles.css` as above; if you import [only the palettes you use](/themes/docs/overview/styling#per-component-css), import `tokens.css` (or every palette) and, in split mode, `css/theme-panel.css` while the panel is mounted.
