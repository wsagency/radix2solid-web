# Radix2Solid website implementation

Unofficial native Solid 2 documentation and examples, not the official Radix website or a WorkOS product. Historical original React blog posts, case studies, designs and endorsements retain attribution. Start with the [root bootstrap/install instructions](../../README.md).

The exact inventory is owned by [`coverage-manifest.json`](coverage-manifest.json): 174 MDX documents, 189 routes plus 404, 278 demo files and 119 archives. It preserves 137 original documents and 151 original routes; 37 documents and 38 routes are native-only, including seven Primitives API pages and seven Themes component recipes. The six Calendar, DatePicker and FileDrop guides/recipes are local-candidate documentation: their new exports are not in published `0.1.0-rc.3`. Original routes were independently observed at the recorded upstream commit; both component indexes have real HTML/Markdown routes.

## Commands from the web root

```sh
node scripts/prepare-library.ts
pnpm install --frozen-lockfile
pnpm build
pnpm typecheck
pnpm --filter @radix-solid/website check:export
pnpm --filter @radix-solid/website check:snippets
pnpm --filter @radix-solid/website check:examples
pnpm --filter @radix-solid/website check:sandboxes
pnpm --filter @radix-solid/website test
pnpm exec playwright test
node apps/website/scripts/check-dev.mjs
pnpm dev
```
